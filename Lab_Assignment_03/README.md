# CS509 Assignment 3 - Individual Task

## Minimum Spanning Tree (MST)

This project implements the individual part of Assignment 3:

- Kruskal's Minimum Spanning Tree algorithm
- Prim's Minimum Spanning Tree algorithm
- Weighted undirected graphs
- CSR graph representation
- Separate timing for each algorithm
- Same graph inputs for both algorithms

The implementation follows the project organization used in the previous assignments.

## Input Format

Each MST input file uses the weighted undirected adjacency-list format:

```text
V E
u degree neighbor1 weight1 neighbor2 weight2 ...
...
```

`E` counts each undirected edge only once, although the edge occurs in both endpoint adjacency lists.

Example:

```text
5 7
0 2 1 2 3 6
1 4 0 2 2 3 3 8 4 5
2 2 1 3 4 7
3 3 0 6 1 8 4 9
4 3 1 5 2 7 3 9
```

Vertices are numbered from `0` to `V-1`.

---

## CSR Conversion

The input adjacency list is converted to CSR before either algorithm is called.

The CSR representation contains:

- `row_ptr`
- `col_idx`
- `values`

The conversion is preprocessing and is outside the measured algorithm time.

The CSR parser intentionally uses C-style file handling:

- `FILE *`
- `fopen`
- `fscanf`
- `fgets`
- `strtok`
- `atoi`
- `fclose`

The parsing approach is based on the supplied/shared CSR code.

---

## Kruskal

Kruskal:

1. Extracts each undirected edge once from CSR.
2. Sorts edges by non-decreasing weight.
3. Uses DSU/Union-Find to detect cycles.
4. Adds an edge when its endpoints are in different components.
5. Stops after `V-1` edges.

Approximate complexity:

```text
O(E log E)
```

---

## Prim

Prim:

1. Starts from vertex `0`.
2. Uses a min-priority queue.
3. Repeatedly selects the minimum-weight edge that connects
   the current tree to an unvisited vertex.
4. Continues until all vertices are included.

Using a binary heap:

```text
O(E log V)
```

## Timing

Only the algorithm execution is timed.

The following are NOT included:

- file opening
- file reading
- parsing
- CSR conversion
- output generation
- comparison/printing

Timing is reported in microseconds.

## Compilation

Linux/macOS:

```bash
g++ -std=c++17 -O2 driver.cpp mst.cpp make_csr.cpp -o run.out
```

Run:

```bash
./run.out
```

Or use:

```bash
./run
```

The `run` script compiles and starts the program.

---

## Output

For each input file, an output file is created in:

```text
testcases/outputs/mst/
```

For example:

```text
mst_100.txt
```

produces:

```text
mst_100.txt_output.txt
```

The output contains:

- test-case information
- selected MST edges
- total MST weight
- algorithm execution time
- comparison of Kruskal and Prim when both are selected

Both algorithms must produce the same minimum total weight. The actual selected edges may differ when multiple MSTs exist.

---

## Notes

The generated test graphs are connected sparse weighted undirected graphs. Every undirected edge is stored in both endpoint adjacency lists with the same weight.

Large graphs use approximately `E = 2V` edges, which keeps them sparse while providing useful performance tests.
